1. 这是什么？

联盟每隔几个月重新分配一次卫星。各军团申请想要的卫星，Auth 根据活跃度为每个军团评分，并自动、透明地分配卫星。 {% if s.exclude_r64 %}R64 卫星由联盟保留，不参与分配。{% endif %}

2. 流程
  1. Mining Officer 准备并开启一轮分配。
  2. 开启后申请期为 {{ s.application_days }} 天。截止前可以随时修改申请。
  3. 时间结束后，本轮会自动评分并只分配一次。
  4. 所有申请人都会收到包含结果的 Auth 通知。完整排名可在本轮页面查看。
3. 谁可以申请？

联盟军团的 CEO – 每个军团一份申请。{% if s.allow_directors %} 董事也可以申请；董事通过 Corptools 识别，因此角色需要有效的 Corptools 审计。{% endif %}

{% if s.probation_months %}

你的军团必须已加入联盟至少 {{ s.probation_months }} 个月（从最近一次加入算起）。仍在考察期内的军团不能申请；Mining Officer 可以给予例外。

{% endif %}

无法登录 Auth（例如由于中国防火墙）？请向 Mining Officer 索取本轮的 Excel 模板：填写军团代号，在想要的卫星旁填写 x，然后把文件发回 – officer 会将其导入。在 Auth 中没有任何玩家的军团只按 PvP 和舰队评分。

4. 如何申请
  1. 打开 Moon Distribution → 轮次，点击你军团旁边的申请。
  2. 勾选你军团想要的所有卫星 – 最多 {{ s.max_wishes }} 个。卫星按星域分在不同标签页中，选择在所有标签页中通用。
  3. 点击列标题即可排序（例如按稀有度或高价值矿石占比）；Shift+点击可添加第二级排序。
  4. 保存。所有勾选的卫星同等对待 – 没有优先顺序。

颜色： R32 R16 R8 R4. 卫星旁的标签显示其矿石及占比；最高 % 是该卫星等级中最有价值矿石的占比。

5. 军团如何评分

7. 卫星如何分配
  1. 所有申请军团按总分排序（同分时先申请者优先）。
  2. 各军团依次获得一个卫星：在其勾选的卫星中仍空闲的最好的一个（先看稀有度，再看高价值矿石占比）。
  3. 然后从最高分军团开始下一轮，直到每个军团获得 {{ s.max_moons_per_corp }} 个卫星，或其想要的卫星都已被分走。

每个军团每轮的上限： {% if s.max_r32_per_corp is not None %}max. {{ s.max_r32_per_corp }} × R32{% endif %} {% if s.max_r16_per_corp is not None %}, max. {{ s.max_r16_per_corp }} × R16{% endif %} – 达到上限后，将改为分配另一等级的下一个空闲卫星。

8. 建议
  • 勾选足够多的卫星——如果在轮到你之前你想要的卫星都被分走，你的军团将一无所获。
  • 确保所有成员都已在 Auth 中注册角色——只有注册的玩家才算活跃成员。
  • 参加带 FAT 链接的舰队并积极战斗——这最重要。
