1. Про що йдеться?

Раз на кілька місяців альянс заново розподіляє свої місяці. Корпорації подають заявки на потрібні місяці, Auth оцінює кожну корпорацію за її активністю та розподіляє місяці автоматично й прозоро. {% if s.exclude_r64 %}R64 місяці залишаються в альянсі й не розподіляються.{% endif %}

2. Порядок проведення
  1. Mining Officer'и готують раунд і відкривають його.
  2. З цього моменту прийом заявок відкритий {{ s.application_days }} дн. До кінця терміну заявку можна змінювати будь-коли.
  3. Після закінчення терміну раунд автоматично оцінюється та розподіляється рівно один раз.
  4. Усі, хто подав заявку, отримують сповіщення в Auth із результатом. Повний рейтинг видно на сторінці раунду.
3. Хто може подати заявку?

CEO корпорації альянсу – одна заявка на корпорацію.{% if s.allow_directors %} Подавати заявку можуть і директори; їх визначають через Corptools, тому персонаж має мати активний аудит Corptools.{% endif %}

{% if s.probation_months %}

Ваша корпорація має бути в альянсі щонайменше {{ s.probation_months }} міс. (рахуючи від останнього вступу). Корпорації на випробувальному терміні не можуть подавати заявки; Mining Officer'и можуть зробити виняток.

{% endif %}
4. Як подати заявку
  1. Відкрийте Moon Distribution → Раунди і натисніть Подати заявку біля своєї корпорації.
  2. Позначте всі місяці, які потрібні вашій корпорації – до {{ s.max_wishes }}. Місяці згруповані за регіонами у вкладках; вибір діє в усіх вкладках.
  3. Натисніть на заголовок стовпця, щоб відсортувати (наприклад, за рідкістю або часткою цінної руди); Shift+клік додає другий рівень сортування.
  4. Збережіть. Усі позначені місяці рівноцінні – порядку пріоритетів немає.

Кольори: R32 R16 R8 R4. Мітки біля місяця показують його руди та їхню частку; Найкращий % – частка найціннішої руди класу місяця.

5. Як оцінюються корпорації

Вимірюється активність за період, указаний у раунді (зазвичай останні ~6 місяців). Кожен критерій масштабується від 0 до 100 відносно найкращої корпорації-заявника; зважене середнє – це ваш результат.

7. Як розподіляються місяці
  1. Усі корпорації-заявники сортуються за загальним результатом (за рівності перемагає раніша заявка).
  2. По черзі кожна корпорація отримує один місяць: найкращий із позначених, який ще вільний (спочатку рідкість, потім частка цінної руди).
  3. Потім починається наступне коло, знову з найкращої корпорації – доки кожна корпорація не матиме {{ s.max_moons_per_corp }} місяців або жоден із її місяців не залишиться вільним.

Ліміти на корпорацію за раунд: {% if s.max_r32_per_corp is not None %}max. {{ s.max_r32_per_corp }} × R32{% endif %} {% if s.max_r16_per_corp is not None %}, max. {{ s.max_r16_per_corp }} × R16{% endif %} – якщо ваша корпорація досягла ліміту, вона отримує наступний вільний місяць іншого класу.

8. Поради
  • Позначайте достатньо місяців – якщо всі ваші місяці розберуть до вашої черги, корпорація нічого не отримає.
  • Переконайтеся, що всі учасники зареєстрували своїх персонажів в Auth – лише зареєстровані гравці вважаються активними учасниками.
  • Літайте у флотах із FAT-посиланнями та бийтеся – це важить найбільше.
