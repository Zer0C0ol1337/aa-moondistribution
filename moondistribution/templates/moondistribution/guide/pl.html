1. O co chodzi?

Co kilka miesięcy sojusz na nowo dzieli swoje księżyce. Korporacje zgłaszają się po księżyce, które chcą, Auth ocenia każdą corp według jej aktywności i przydziela księżyce automatycznie i przejrzyście. {% if s.exclude_r64 %}R64 księżyce zostają przy sojuszu i nie są rozdzielane.{% endif %}

2. Przebieg
  1. Mining Officerowie przygotowują rundę i ją otwierają.
  2. Od tego momentu zgłoszenia są otwarte przez {{ s.application_days }} dni. Do terminu możecie w każdej chwili zmienić zgłoszenie.
  3. Po upływie czasu runda jest automatycznie oceniana i rozdzielana dokładnie raz.
  4. Wszyscy zgłaszający dostają powiadomienie w Auth z wynikiem. Pełny ranking jest widoczny na stronie rundy.
3. Kto może się zgłosić?

CEO korporacji z sojuszu – jedno zgłoszenie na corp.{% if s.allow_directors %} Zgłaszać się mogą też dyrektorzy; są rozpoznawani przez Corptools, więc postać potrzebuje aktywnego audytu Corptools.{% endif %}

{% if s.probation_months %}

Wasza corp musi być w sojuszu co najmniej {{ s.probation_months }} mies. (licząc od ostatniego dołączenia). Corp w okresie próbnym nie mogą składać zgłoszeń; Mining Officerowie mogą zrobić wyjątek.

{% endif %}

Nie możecie zalogować się do Auth (np. przez chińską zaporę)? Poproście Mining Officera o szablon Excel rundy: wpiszcie ticker waszej corp, postawcie x przy wybranych księżycach i odeślijcie plik – officer go zaimportuje. Corp bez graczy w Auth są wtedy oceniane tylko za PvP i floty.

4. Jak się zgłosić
  1. Otwórzcie Moon Distribution → Rundy i kliknijcie Zgłoś się przy swojej corp.
  2. Zaznaczcie wszystkie księżyce, które chce wasza corp – maksymalnie {{ s.max_wishes }}. Księżyce są pogrupowane w zakładki według regionu; wybór obowiązuje we wszystkich zakładkach.
  3. Kliknięcie nagłówka kolumny sortuje (np. według rzadkości lub udziału cennej rudy); Shift+klik dodaje drugi poziom sortowania.
  4. Zapiszcie. Wszystkie zaznaczone księżyce liczą się tak samo – nie ma kolejności priorytetów.

Kolory: R32 R16 R8 R4. Etykiety obok księżyca pokazują jego rudy i ich udział; Najlepszy % to udział najcenniejszej rudy danej klasy księżyca.

5. Jak oceniane są korporacje

Mierzona jest aktywność w okresie podanym przy rundzie (zwykle ostatnie ~6 miesięcy). Każde kryterium jest skalowane od 0 do 100 względem najlepszej zgłaszającej się corp; średnia ważona to wasz wynik.

7. Jak przydzielane są księżyce
  1. Wszystkie zgłoszone korporacje są sortowane według łącznego wyniku (przy remisie wygrywa wcześniejsze zgłoszenie).
  2. Po kolei każda corp dostaje jeden księżyc: najlepszy z zaznaczonych, który jest jeszcze wolny (najpierw rzadkość, potem udział cennej rudy).
  3. Potem zaczyna się kolejna tura, znowu od najlepszej corp – aż każda corp ma {{ s.max_moons_per_corp }} księżyce albo żaden z jej księżyców nie jest już wolny.

Limity na corp i rundę: {% if s.max_r32_per_corp is not None %}max. {{ s.max_r32_per_corp }} × R32{% endif %} {% if s.max_r16_per_corp is not None %}, max. {{ s.max_r16_per_corp }} × R16{% endif %} – jeśli wasza corp osiągnie limit, dostaje zamiast tego następny wolny księżyc innej klasy.

8. Wskazówki
  • Zaznaczcie wystarczająco dużo księżyców – jeśli wszystkie zostaną rozdane przed waszą kolejką, corp nic nie dostanie.
  • Upewnijcie się, że wszyscy członkowie zarejestrowali swoje postacie w Auth – tylko zarejestrowani gracze liczą się jako aktywni członkowie.
  • Latajcie we flotach z linkami FAT i walczcie – to liczy się najbardziej.
