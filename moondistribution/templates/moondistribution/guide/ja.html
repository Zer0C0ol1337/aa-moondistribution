1. 概要

アライアンスは数か月ごとにムーンを再分配します。各コーポは希望するムーンに申請し、Auth が活動量に基づいて各コーポを評価し、ムーンを自動的かつ透明に割り当てます。 {% if s.exclude_r64 %}R64 ムーンはアライアンスが保持し、分配されません。{% endif %}

2. 流れ
  1. マイニングオフィサーがラウンドを準備して開始します。
  2. 開始から{{ s.application_days }}日間申請を受け付けます。締め切りまではいつでも申請を変更できます。
  3. 期間が終わると、ラウンドは自動的に評価され、一度だけ分配されます。
  4. 申請した全員に結果が Auth の通知で届きます。ランキング全体はラウンドのページで確認できます。
3. 申請できるのは？

アライアンス所属コーポのCEO – 1コーポにつき1件の申請です。{% if s.allow_directors %} ディレクターも申請できます。ディレクターは Corptools で判定されるため、キャラクターに有効な Corptools 監査が必要です。{% endif %}

{% if s.probation_months %}

コーポは同盟に少なくとも{{ s.probation_months }}か月在籍している必要があります（最後の加入日から数えます）。試用期間中のコーポは申請できません。マイニングオフィサーは例外を認めることができます。

{% endif %}
4. 申請方法
  1. Moon Distribution → ラウンドを開き、自分のコーポの横にある申請をクリックします。
  2. コーポが希望するムーンをすべてチェックします（最大{{ s.max_wishes }}件）。ムーンはリージョンごとのタブに分かれており、選択はすべてのタブで共通です。
  3. 列の見出しをクリックすると並べ替えできます（例：レア度や高価値鉱石の割合）。Shift+クリックで2段階目の並べ替えを追加できます。
  4. 保存します。チェックしたムーンはすべて同等に扱われ、優先順位はありません。

色： R32 R16 R8 R4. ムーンの横のラベルは鉱石とその割合を示します。最高 % はそのムーンのクラスで最も価値の高い鉱石の割合です。

5. コーポの評価方法

7. ムーンの割り当て方法
  1. 申請したすべてのコーポを合計スコア順に並べます（同点の場合は先に申請したコーポが上位）。
  2. 順番に各コーポが1つのムーンを受け取ります。チェックしたムーンのうち、まだ空いている最良のもの（まずレア度、次に高価値鉱石の割合）です。
  3. その後、再び最上位のコーポから次の周回が始まり、各コーポが{{ s.max_moons_per_corp }}個のムーンを得るか、希望ムーンがすべて埋まるまで続きます。

1コーポ・1ラウンドあたりの上限： {% if s.max_r32_per_corp is not None %}max. {{ s.max_r32_per_corp }} × R32{% endif %} {% if s.max_r16_per_corp is not None %}, max. {{ s.max_r16_per_corp }} × R16{% endif %} – 上限に達した場合は、代わりに別クラスの次の空いているムーンが割り当てられます。

8. ヒント
  • 十分な数のムーンをチェックしてください。自分の番の前に希望ムーンがすべて埋まると、コーポは何も得られません。
  • 全メンバーがキャラクターを Auth に登録しているか確認してください。登録済みのプレイヤーだけがアクティブメンバーとして数えられます。
  • FATリンク付きのフリートに参加して戦いましょう。それが最も重要です。
