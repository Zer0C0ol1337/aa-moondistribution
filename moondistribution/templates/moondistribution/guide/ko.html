1. 개요

얼라이언스는 몇 달마다 위성을 다시 분배합니다. 각 코퍼레이션은 원하는 위성에 신청하고, Auth가 활동량으로 코퍼레이션을 평가하여 위성을 자동으로, 투명하게 배정합니다. {% if s.exclude_r64 %}R64 위성은 얼라이언스가 보유하며 분배되지 않습니다.{% endif %}

2. 진행 순서
  1. 마이닝 오피서가 라운드를 준비하고 엽니다.
  2. 그때부터 {{ s.application_days }}일 동안 신청을 받습니다. 마감 전까지 언제든지 신청을 변경할 수 있습니다.
  3. 기간이 끝나면 라운드가 자동으로 평가되고 정확히 한 번 분배됩니다.
  4. 신청한 모든 사람은 결과가 담긴 Auth 알림을 받습니다. 전체 순위는 라운드 페이지에서 볼 수 있습니다.
3. 누가 신청할 수 있나요?

얼라이언스 소속 코퍼레이션의 CEO – 코퍼레이션당 신청 1건.{% if s.allow_directors %} 디렉터도 신청할 수 있습니다. 디렉터는 Corptools로 확인하므로 캐릭터에 활성화된 Corptools 감사가 필요합니다.{% endif %}

4. 신청 방법
  1. Moon Distribution → 라운드를 열고 내 코퍼레이션 옆의 신청을 클릭합니다.
  2. 코퍼레이션이 원하는 위성을 모두 체크합니다 – 최대 {{ s.max_wishes }}개. 위성은 지역별 탭으로 나뉘어 있으며, 선택은 모든 탭에 걸쳐 적용됩니다.
  3. 열 제목을 클릭하면 정렬됩니다(예: 희귀도 또는 고가치 광석 비율). Shift+클릭으로 두 번째 정렬 기준을 추가할 수 있습니다.
  4. 저장합니다. 체크한 위성은 모두 동등하게 취급되며 우선순위는 없습니다.

색상: R32 R16 R8 R4. 위성 옆의 라벨은 광석과 그 비율을 보여 줍니다. 최고 %는 해당 위성 등급에서 가장 가치 있는 광석의 비율입니다.

5. 코퍼레이션 평가 방식

라운드에 표시된 기간(보통 최근 약 6개월)의 활동을 측정합니다. 각 기준은 신청한 코퍼레이션 중 최고를 100으로 하여 0~100으로 환산되며, 가중 평균이 점수가 됩니다.

7. 위성 배정 방식
  1. 신청한 모든 코퍼레이션을 총점 순으로 정렬합니다(동점이면 먼저 신청한 쪽이 우선).
  2. 차례대로 각 코퍼레이션이 하나의 위성을 받습니다: 체크한 위성 중 아직 남아 있는 가장 좋은 위성(먼저 희귀도, 그다음 고가치 광석 비율).
  3. 그다음 다시 최고 코퍼레이션부터 다음 바퀴가 시작되며, 각 코퍼레이션이 {{ s.max_moons_per_corp }}개의 위성을 받거나 원하는 위성이 모두 소진될 때까지 계속됩니다.

코퍼레이션·라운드당 한도: {% if s.max_r32_per_corp is not None %}max. {{ s.max_r32_per_corp }} × R32{% endif %} {% if s.max_r16_per_corp is not None %}, max. {{ s.max_r16_per_corp }} × R16{% endif %} – 한도에 도달하면 대신 다른 등급의 다음 남은 위성이 배정됩니다.

8. 팁
  • 위성을 충분히 체크하세요. 내 차례 전에 원하는 위성이 모두 배정되면 코퍼레이션은 아무것도 받지 못합니다.
  • 모든 멤버가 Auth에 캐릭터를 등록했는지 확인하세요. 등록된 플레이어만 활동 멤버로 계산됩니다.
  • FAT 링크가 있는 함대에 참여하고 싸우세요. 그것이 가장 중요합니다.
