1. О чём речь?

Раз в несколько месяцев альянс заново распределяет свои луны. Корпорации подают заявки на нужные им луны, Auth оценивает каждую корпорацию по её активности и распределяет луны автоматически и прозрачно. {% if s.exclude_r64 %}R64 луны остаются у альянса и не распределяются.{% endif %}

2. Порядок проведения
  1. Mining Officer'ы готовят раунд и открывают его.
  2. С этого момента приём заявок открыт {{ s.application_days }} дн. До окончания срока заявку можно менять в любое время.
  3. По истечении срока раунд автоматически оценивается и распределяется ровно один раз.
  4. Все подавшие заявку получают уведомление в Auth с результатом. Полный рейтинг виден на странице раунда.
3. Кто может подать заявку?

CEO корпорации альянса – одна заявка на корпорацию.{% if s.allow_directors %} Подавать заявку могут и директора; они определяются через Corptools, поэтому у персонажа должен быть активный аудит Corptools.{% endif %}

{% if s.probation_months %}

Ваша корпорация должна состоять в альянсе не менее {{ s.probation_months }} мес. (считая с последнего вступления). Корпорации на испытательном сроке не могут подавать заявки; Mining Officer'ы могут сделать исключение.

{% endif %}

Не получается войти в Auth (например, из-за китайского файрвола)? Попросите у Mining Officer'а шаблон Excel раунда: впишите тикер корпорации, поставьте x рядом с нужными лунами и отправьте файл обратно – officer его импортирует. Корпорации без игроков в Auth тогда оцениваются только по PvP и флотам.

4. Как подать заявку
  1. Откройте Moon Distribution → Раунды и нажмите Подать заявку рядом со своей корпорацией.
  2. Отметьте все луны, которые нужны вашей корпорации – до {{ s.max_wishes }}. Луны сгруппированы по регионам во вкладках; выбор действует во всех вкладках.
  3. Нажмите на заголовок столбца для сортировки (например, по редкости или по доле ценной руды); Shift+клик добавляет второй уровень сортировки.
  4. Сохраните. Все отмеченные луны равноценны – порядка приоритетов нет.

Цвета: R32 R16 R8 R4. Метки рядом с луной показывают её руды и их долю; Лучший % – доля самой ценной руды класса луны.

5. Как оцениваются корпорации

Измеряется активность за период, указанный в раунде (обычно последние ~6 месяцев). Каждый критерий масштабируется от 0 до 100 относительно лучшей корпорации-заявителя; взвешенное среднее – это ваш результат.

7. Как распределяются луны
  1. Все корпорации-заявители сортируются по общему результату (при равенстве побеждает более ранняя заявка).
  2. По очереди каждая корпорация получает одну луну: лучшую из отмеченных, которая ещё свободна (сначала редкость, затем доля ценной руды).
  3. Затем начинается следующий круг, снова с лучшей корпорации – пока у каждой корпорации не будет {{ s.max_moons_per_corp }} лун или пока ни одна из её лун не останется свободной.

Лимиты на корпорацию за раунд: {% if s.max_r32_per_corp is not None %}max. {{ s.max_r32_per_corp }} × R32{% endif %} {% if s.max_r16_per_corp is not None %}, max. {{ s.max_r16_per_corp }} × R16{% endif %} – если ваша корпорация достигла лимита, она получает следующую свободную луну другого класса.

8. Советы
  • Отмечайте достаточно лун – если все ваши луны разберут до вашей очереди, корпорация ничего не получит.
  • Убедитесь, что все участники зарегистрировали своих персонажей в Auth – только зарегистрированные игроки считаются активными участниками.
  • Летайте во флотах с FAT-ссылками и сражайтесь – это важнее всего.
