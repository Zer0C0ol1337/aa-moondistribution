1. De quoi s'agit-il ?

Tous les quelques mois, l'alliance redistribue ses lunes. Les corps postulent pour les lunes qu'elles souhaitent, l'Auth évalue chaque corp selon son activité et attribue les lunes de façon automatique et transparente. {% if s.exclude_r64 %}R64 lunes restent à l'alliance et ne sont pas distribuées.{% endif %}

2. Déroulement
  1. Les Mining Officers préparent un tour et l'ouvrent.
  2. À partir de là, les candidatures sont ouvertes pendant {{ s.application_days }} jours. Vous pouvez modifier votre candidature à tout moment jusqu'à la clôture.
  3. Une fois le délai écoulé, le tour est évalué et distribué automatiquement, une seule fois.
  4. Tous les candidats reçoivent une notification de l'Auth avec le résultat. Le classement complet est visible sur la page du tour.
3. Qui peut postuler ?

Le CEO d'une corp de l'alliance – une candidature par corp.{% if s.allow_directors %} Les directeurs peuvent aussi postuler ; ils sont reconnus via Corptools, le personnage doit donc avoir un audit Corptools actif.{% endif %}

{% if s.probation_months %}

Votre corp doit faire partie de l'alliance depuis au moins {{ s.probation_months }} mois (à compter de sa dernière adhésion). Les corps encore en période d'essai ne peuvent pas postuler ; les Mining Officers peuvent faire une exception.

{% endif %}

Vous ne pouvez pas vous connecter à l'Auth (par ex. à cause du pare-feu chinois) ? Demandez à un Mining Officer le modèle Excel de la manche : saisissez le ticker de votre corp, mettez un x à côté des lunes souhaitées et renvoyez le fichier – l'officer l'importe. Les corps sans aucun joueur dans l'Auth sont alors évaluées uniquement sur le PvP et les flottes.

4. Comment postuler
  1. Ouvrez Moon Distribution → Tours et cliquez sur Postuler à côté de votre corp.
  2. Cochez toutes les lunes que votre corp souhaite – jusqu'à {{ s.max_wishes }}. Les lunes sont regroupées par région dans des onglets ; votre sélection vaut pour tous les onglets.
  3. Cliquez sur un en-tête de colonne pour trier (par ex. par rareté ou par la part du minerai précieux) ; Maj+clic ajoute un second niveau de tri.
  4. Enregistrez. Toutes les lunes cochées comptent de la même façon – il n'y a pas d'ordre de priorité.

Couleurs : R32 R16 R8 R4. Les étiquettes à côté d'une lune indiquent ses minerais et leur part ; Meilleur % est la part du minerai le plus précieux de la classe de la lune.

5. Comment les corps sont évaluées

L'activité est mesurée sur la période indiquée pour le tour (généralement les ~6 derniers mois). Chaque critère est ramené sur une échelle de 0 à 100 par rapport à la meilleure corp candidate ; la moyenne pondérée donne votre score.

7. Comment les lunes sont attribuées
  1. Toutes les corps candidates sont classées selon leur score total (en cas d'égalité, la candidature la plus ancienne l'emporte).
  2. Chacune son tour, chaque corp reçoit une lune : la meilleure de ses lunes cochées encore libre (d'abord la rareté, puis la part du minerai précieux).
  3. Puis le tour suivant recommence avec la meilleure corp – jusqu'à ce que chaque corp ait {{ s.max_moons_per_corp }} lunes ou qu'aucune de ses lunes ne soit encore libre.

Limites par corp et par tour : {% if s.max_r32_per_corp is not None %}max. {{ s.max_r32_per_corp }} × R32{% endif %} {% if s.max_r16_per_corp is not None %}, max. {{ s.max_r16_per_corp }} × R16{% endif %} – si votre corp atteint une limite, elle reçoit à la place la prochaine lune libre d'une autre classe.

8. Conseils
  • Cochez assez de lunes : si toutes vos lunes sont attribuées avant votre tour, votre corp n'obtient rien.
  • Veillez à ce que tous les membres aient enregistré leurs personnages dans l'Auth : seuls les joueurs enregistrés comptent comme membres actifs.
  • Volez en flotte avec des liens FAT et combattez – c'est ce qui compte le plus.
